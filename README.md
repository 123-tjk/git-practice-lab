# Git 实操练习实验室 / git-practice-lab

这是一份**完整流程**的 Git 动手练习：从 Fork、本地工作区/暂存区/提交，到分支与合并、历史回溯、submodule，再到同步上游并提交 Pull Request。

This is a complete hands-on Git lab: fork → local practice → open a Pull Request back here.

## 如何开始 / How to start

1. **Fork** 本仓库：https://github.com/kiramint/git-practice-lab
2. **Clone 你自己的 fork**（不要直接 clone 本仓库当日常工作副本）
3. 按 [docs/ASSIGNMENT.md](docs/ASSIGNMENT.md) 分阶段完成练习
4. 填写 [submissions/LAB_REPORT.md](submissions/LAB_REPORT.md)
5. 推送到你的功能分支，并向 **`kiramint/git-practice-lab`** 的 **`main`** 分支开 Pull Request

## 伴侣仓库（Submodule 用）

Stage 4 会用到：

- https://github.com/kiramint/git-practice-kit

> 本仓库**不会**预先添加 submodule，你必须自己在 Stage 4 添加。

## 规则 / Rules

- **不要**提交密钥、token、密码等敏感信息
- 在功能分支上工作，分支名：`lab/<your-github-username>`（例如 `lab/alice`）
- PR 标题格式：`[Lab] <username> 完成 Git 实操`
- 交卷内容以填写好的 `submissions/LAB_REPORT.md` 与相关提交记录为准

## 给维护者（Kira）

把收到的 Pull Request 当作作业提交来审阅：核对 LAB_REPORT 勾选与关键 commit，必要时在 PR 里留言反馈。
